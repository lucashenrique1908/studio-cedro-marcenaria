Studio Cedro Marcenaria

A responsive website developed for Studio Cedro Marcenaria, a custom furniture company based in Rio de Janeiro, Brazil.

The project was built to give the company a professional online presence, showcase its work and services, and provide potential customers with a simple way to request a quote.

Technologies:
React,
JavaScript,
Vite,
CSS,
Responsive Design,
Features,
Responsive company website,
Services and projects showcase,
About the company section,
Quote request form,
Customer review section,
WhatsApp integration,
Instagram integration,
Responsive navigation and UI,

Live Website: https://www.studiocedromarcenaria.com/

Project:
Developed as a real-world project for Studio Cedro Marcenaria, with a focus on translating the company's identity and services into a functional web experience.
